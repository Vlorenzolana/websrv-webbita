🚀 Webserv Evaluation Tester

Configuración Global

Cambia esto al puerto donde tu webserv esté escuchando. Actualizará los comandos curl automáticamente.

1. Métodos Básicos y Rutas

GET Listado de Directorio (Autoindex)

Prueba si el servidor lista correctamente los archivos de un directorio.

Resultado...

Comando cURL:

curl -i -X GET "[URL]/dir_list"

GET URL Incorrecta (Custom 404)

Prueba una ruta que no existe para verificar la página de error por defecto.

Resultado...

Comando cURL:

curl -i -X GET "[URL]/ruta_que_no_existe"

GET Redirección

Verifica si una URL configurada redirige correctamente (301 o 302).

Resultado...

Comando cURL:

curl -i -X GET "[URL]/old-route"

2. POST y Límites de Body

POST Límite de Body (Correcto)

Envía un payload pequeño que debería ser aceptado por el servidor.

Resultado...

Comando cURL:

curl -i -X POST -H "Content-Type: text/plain" --data "Texto corto" "[URL]/upload"

POST Límite de Body (Excedido)

Envía un payload grande para provocar un error 413 Payload Too Large.

Resultado...

Comando cURL:

curl -i -X POST -H "Content-Type: text/plain" --data "A... (texto gigante)" "[URL]/upload"

3. Permisos y Métodos Desconocidos

DELETE Método Permitido

Prueba a borrar un archivo en una ruta con permisos.

Resultado...

Comando cURL:

curl -i -X DELETE "[URL]/delete_allowed/test.txt"

DELETE Método Denegado

Prueba a borrar un archivo donde el método no está aceptado (Debe dar 405 Method Not Allowed).

Resultado...

Comando cURL:

curl -i -X DELETE "[URL]/delete_denied/test.txt"

UNKNOWN Método Desconocido

Prueba un método HTTP inventado para asegurar que el servidor no crashea (501 Not Implemented o 400).

Resultado...

Comando cURL:

curl -i -X PURGE "[URL]/"

4. Common Gateway Interface (CGI)

CGI GET Ejecución de Script GET

Verifica que el CGI se ejecuta correctamente y devuelve resultados.

Resultado...

Comando cURL:

curl -i -X GET "[URL]/cgi-bin/test.py?name=Evaluator"

CGI POST Ejecución de Script POST

Verifica que el CGI recibe el body correctamente por STDIN.

Resultado...

Comando cURL:

curl -i -X POST -d "name=Evaluator&project=Webserv" "[URL]/cgi-bin/test.py"

CGI ERROR CGI con Fallo / Bucle

Verifica el manejo de errores del servidor (Timeout o 500 Internal Server Error) sin crashear.

Resultado...

Comando cURL:

curl -i -X GET "[URL]/cgi-bin/infinite.py"

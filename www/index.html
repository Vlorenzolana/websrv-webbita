2. Comandos de Terminal

Haz clic en "Copiar" y pégalo en la terminal del evaluador.

Método Desconocido (Anti-Crash): curl -i -X INVENTO http://127.0.0.1:8081/
Límite de Body (Error 413): curl -i -X POST -H "Content-Type: text/plain" --data "Texto gigante" http://127.0.0.1:8081/
Upload Binario Puro por curl: curl -i -X POST --data-binary @webserv http://127.0.0.1:8081/uploads/webserv_copy
Path Traversal (Seguridad 403/404): curl -i --path-as-is http://127.0.0.1:8081/../../../../etc/passwd
Prueba de Estrés (Siege): siege -b -c 100 -t 30S http://127.0.0.1:8081/

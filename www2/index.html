5. Virtual Hosts (Pruebas por Terminal)

Demuestra el enrutamiento basado en server_name compartiendo el mismo puerto. Inyectamos la cabecera Host manualmente con cURL.

VHOST 1 server_name: localhost

Apunta al bloque con root ./www;

Comando cURL (Index):

curl -i -X GET -H "Host: localhost" "http://127.0.0.1:8081/"

VHOST 2 server_name: localhost2

Apunta al bloque con root ./www2;

Comando cURL (Index de www2):

curl -i -X GET -H "Host: localhost2" "http://127.0.0.1:8081/"

Comando cURL (404 personalizado de www2):

curl -i -X GET -H "Host: localhost2" "http://127.0.0.1:8081/missing"

Comando cURL (Subida de prueba en www2):

curl -i -X POST -H "Host: localhost2" -H "Content-Type: text/plain" -d "Archivo subido por VHOST2" "http://127.0.0.1:8081/uploads/test_vhost2.txt"

6. Pruebas por Terminal (Casos Límite y Estrés)

Ejecuta estos comandos en tu terminal (WSL/Linux). Comprueban el timeout de CGI y el correcto manejo del epoll con conexiones no bloqueantes.

TERMINAL Petición Truncada (Incompleta)

Promete un cuerpo grande pero corta la conexión abruptamente enviando solo una línea. El servidor no debe colgarse.

(echo -ne "POST /uploads/trunc.txt HTTP/1.1\r\nHost: localhost\r\nContent-Length: 5000\r\n\r\nSolo envio esto...") | nc -w 2 127.0.0.1 8081

TERMINAL Petición Fragmentada (Byte a Byte)

Envía la petición muy lentamente. Demuestra que epoll no bloquea a otros clientes.

(echo -ne "GE"; sleep 1; echo -ne "T / HT"; sleep 1; echo -ne "TP/1.1\r\n"; sleep 1; echo -ne "Host: localhost\r\n\r\n") | nc 127.0.0.1 8081

TERMINAL Transfer-Encoding: chunked

Verifica que el servidor recibe y desfragmenta el cuerpo correctamente.

curl -i -X POST -H "Transfer-Encoding: chunked" -d "Prueba de chunks enviada por curl" "[URL]/uploads/chunked.txt"

TERMINAL CGI Timeout (10s)

Invoca a hold.py. El servidor debe matarlo a los 25s y devolver 504 Gateway Timeout.

curl -i "[URL]/cgi-bin/hold.py"

TERMINAL Prueba de Estrés (Siege)

Lanza 100 clientes concurrentes haciendo 50 repeticiones cada uno (>99.5% disponibilidad esperada).

siege -b -c 100 -r 50 "[URL]/"

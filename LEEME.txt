  $ killall webserv && sleep 1 && ./webserv config/multivhost.conf

  Recompila todo:
  $ make fclean && make

🎓 PUNTOS TÉCNICOS IMPORTANTES
================================

  Epoll (Non-blocking I/O):
  ╚─ Línea: src/Server.cpp:73
     Método: epoll_create1(), epoll_wait(), epoll_ctl()
     Ventaja: O(1) eficiencia vs select() O(n)

  Multithreading:
  ╚─ Línea: src/main.cpp:60
     Patrón: 1 thread per server con epoll independiente
     Resultado: 3 puertos en paralelo

  Signal Handling:
  ╚─ Línea: src/main.cpp:20
     SIGPIPE ignorado → no crashea en conexiones rotas
     Verificable: kill -PIPE [pid] (no crashes)

  CGI Execution:
  ╚─ Archivo: src/CGIHandler.cpp:29
     Método: fork() + execve() con pipe I/O
     Soporta: Python3, Bash, cualquier script

  Configuration Parser:
  ╚─ Archivo: src/ConfigParser.cpp
     Soporte: Nginx-like syntax (server blocks, locations)
     Validación: ConfigValidator.cpp
